# GridSense

## Description
GridSense is an IoT-based Smart Grid Monitoring System developed using Python. This project helps monitor and analyze electrical grid data efficiently.

## Features
- Monitors grid parameters
- Displays system status
- User-friendly Python implementation
- Educational mini project for students

## Technologies Used
- Python
- Jupyter Notebook

## Project Structure
- GridSense.ipynb

## How to Run
1. Download the repository.
2. Open `GridSense.ipynb` using Jupyter Notebook.
3. Run all the cells to execute the project.
